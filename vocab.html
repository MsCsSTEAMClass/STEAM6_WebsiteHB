Project Vocabulary Guide


Technology & Components

LED (Light Emitting Diode)

A small light that turns on when electricity flows through it.
We use LEDs to show signals, warnings, or information.

EXAMPLE:

  • A red LED lights up when pollution levels are too high.
  • A green LED turns on when conditions are safe.

Sensor

A device that detects something in the environment and sends that invormation to your program.
Sensors are how your project "observes" the world.

EXAMPLE:

  • Temperature sensor
  • Light sensor
  • Distance sensor
  • Moisture sensor

Coding & Programming

Input

Information that goes INTO a system.

EXAMPLE:

  • A sensor reading temperature.
  • A button being pressed.


Variable

A named value that can change in your program.

EXAMPLE:
temperature = 25

If the temperature changes, the variable updates
Variables store data your program needs to make a decision



Ranges

A set of values between two points.
Ranges help systems categorize data.

EXAMPLE:

  • Safe temperature range: 60-75°F
  • Acceptable pH range 6.5-8.5.

Debug

To find and fix errors in your code or design.
Debugging is a normal and important part of engineering.


Output

What a system does in response to an input.

EXAMPLES:

  • Turning on a light
  • Moving a servo
  • Playing a sound

Logic

The "if-then" thinking that controls how your program behaves.
Logic helps your system make decisions.

EXAMPLE:

  • If the water level is above 10cm, then turn on the warning light.
  • If pollution is below the safe threshold, then display "Safe".

Threshold

A specific limit that triggers an action.
Thresholds are decision points.

EXAMPLE:

  • If the temperature goes above 90°F, then trigger alarm.
  • If soil moisture drops below 30%, then activate warning system.

Iteration

Improving your design by testing, revising, and trying again.
Engineers rarely get it perfect the first time.
Iteration means:

  • Test
  • Reflect
  • Improve
  • Repeat

Using Vocabulary in Your Project


TO EARN HIGHER-LEVEL RUBRIC SCORES, TRY TO:

  • Use vocabularly accurately in your presentation
  • Label parts of your system (Input → Process → Output)
  • Explain your thresholds and ranges
  • Describe how you debugged and iterated

Example Explanation:
"The moisture sensor acts as input. The variable "moistureLevel" stores the data.
If the moisture level drops below the threshold of 30%, the system outputs
a signal to the servo motor to open the irrigation valve."
