Sensors, Variables, and Thresholds, Oh My!


Psuedocode:
(soo·doe·kowd)
Pseudocode is a written plan or sketch of what your code needs to do.
Since we will have a sensor that will take in a value, we will need to also create a variable for that value

See Ms. C.'s generic pseudocode below as an example:


VARIABLES

  • Start by creating variables for your sensor value and threshold.
  • Ms. C. left this blank because it could be temperature, light, sound, etc.


ON START

  • Start by setting the Threshold for your sensor value.
  • This will correspond to one of the variables you created.
  • You also need the "Start Hummingbird" code block here.


ON BUTTON 'A' PRESS

  • When you take input from a sensor, it's a good idea to have a way to test and make sure it works!
  • Use "SHOW NUMBER" and the sensor value to see what your sensor is reading!


FOREVER BLOCK

This is where things get a little tricky...

  • Start by setting your VARIABLE value TO the SENSOR INPUT VALUE
  • Then, you'll use an IF/THEN block (from Logic)
  • Use a COMPARISON BLOCK to compare the VARIABLE VALUE to the VARIABLE THRESHOLD
  • Add that COMPARISON BLOCK to the IF/THEN block
  • IF the comparison does what you want, WHAT HAPPENS?
  • ELSE, what happens?


FUNCTIONS

You MAY want to create some functions to help!

Functions are blocks of code that can be reused in other places!

For example, if you are using TEMPERATURE, you may want to convert it FROM Celsius TO Fahrenheit!
